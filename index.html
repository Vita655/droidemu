Android 4.4 (Android-x86) in your browser

Choose an ISO to begin.
How to boot it
  1. When the boot menu appears, choose the VESA mode live entry (arrow keys, then Enter). Other modes fail in v86.
  2. Boot takes several minutes. This is an x86 PC emulated in WebAssembly, so it is slow.
  3. Click the screen and press Capture mouse to control the pointer. Press Esc to release it.

Only versions up to Android-x86 4.4-r2 are known to work with v86. Newer Android versions will not boot.
